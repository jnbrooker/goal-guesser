# Goal Guesser

Learn how many Premier League goals every player scored, for every club, in every season since 1992/93.

A static site (plain HTML/CSS/JS, no build step) that runs on GitHub Pages.

## Modes

| Mode | What it does |
| --- | --- |
| **Browse** | Season tables of every scorer, a club summary, and a "cover goals" self-test toggle |
| **Learn** | Quizlet-style adaptive rounds: multiple choice first, then type it from memory |
| **Flashcards** | Flip cards and mark *know it* / *still learning* (keys: space, 1, 2) |
| **Test** | A marked paper mixing written, multiple choice, true/false, who-scored-more and which-club questions |
| **Name Them** | Sporcle-style list quiz: name every scorer in a season or club against the clock |
| **Higher/Lower** | Streak game comparing two player-seasons |

Each mode has a deck filter (seasons, club, minimum goals). Progress is saved in the browser's localStorage, using a Leitner box per player-season. A player-season counts as mastered after three correct answers in a row.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Data

`data/goals.json` is generated by `scripts/build_data.py` from:

- **1992/93–2019/20**: [TimHoare/Premier_League_Data](https://github.com/TimHoare/Premier_League_Data) (match events)
- **2020/21 onwards**: [vaastav/Fantasy-Premier-League](https://github.com/vaastav/Fantasy-Premier-League) (gameweek data)

League goals only. Penalties are included and own goals are excluded. Only players who scored at least once in a season are listed. A player who moved clubs mid-season gets one row per club.

To rebuild after a season ends, add it to `FPL_SEASONS` in the script, then run:

```bash
python3 scripts/build_data.py
```

To correct an awkward name from the FPL data, add the player to `FPL_NAMES` (keyed by FPL player code) or to `RENAME`.

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages → Build and deployment**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. The site appears at `https://<user>.github.io/<repo>/`.
